Política de Privacidade

Esta política explica como a MONTÊ trata os dados pessoais utilizados para atendimento, compra, pagamento e entrega de pedidos realizados pelo site.

1. Dados utilizados

Podemos tratar nome, e-mail, telefone, CPF, CEP, endereço de entrega, informações do pedido e dados necessários à confirmação do pagamento. Os dados de cartão não são armazenados pela MONTÊ quando o pagamento é processado pela instituição financeira responsável pelo checkout.

2. Finalidades

Os dados são utilizados para processar pedidos, confirmar pagamentos, emitir documentos fiscais quando aplicável, calcular e viabilizar a entrega, atender solicitações, prevenir fraudes e cumprir obrigações legais.

3. Serviços utilizados

O site utiliza serviços de terceiros para determinadas etapas da operação, incluindo InfinitePay para pagamento, SuperFrete para cotação de frete e ViaCEP para consulta de endereço a partir do CEP. Cada serviço possui suas próprias políticas de privacidade.

4. Armazenamento e segurança

Adotamos medidas técnicas e administrativas compatíveis com a operação para proteger os dados contra acesso não autorizado, perda ou uso indevido. O acesso administrativo ao sistema é restrito.

5. Direitos do titular

Nos termos da legislação aplicável, o titular pode solicitar informações sobre o tratamento de seus dados e exercer os direitos previstos na LGPD, observadas as hipóteses legais de conservação.

6. Contato

Para solicitações relacionadas a dados pessoais, utilize os canais de atendimento disponibilizados pela MONTÊ no site.

Esta página apresenta as práticas gerais da loja e não substitui orientação jurídica específica.
